# hxyfront-62012 纺织染整小样管理 · 异常放行台

源提示词编号：7

在染整小样台基础上补建的异常放行台：监测读数触发异常、按序解除、参数变更失效留档、批次评审门禁。

## 业务规则

**异常触发（生成待处置记录，批次不得评审）**

- 温度：连续 3 分钟偏离目标 ≥2℃
- 酸碱：pH 超出 4.5–7.5
- 泡沫：超过批次限值

**解除规则**

- 全台队列按发生顺序解除，只有队首可处置
- 补时只解温度项；酸碱项须连续两次复测合格（不合格清零）；泡沫项须先排泡再复测（复测超限须重新排泡）
- 加急可将本批次处置链提至队首，但不能跳过本批次更早的未闭环异常
- 解除后修改工艺参数：依据旧参数得出的本项及后续结论全部失效、旧履历留档，并按原类型重新生成待处置记录

## 架构（状态计算 / 持久化 / 页面交互分离）

```
src/
  domain/
    types.ts   类型与判定阈值常量
    engine.ts  纯函数状态计算：触发、队列、解除、失效、评审（无 IO，时间戳注入）
    seed.ts    演示数据（经引擎动作构建，保证与时间线一致）
  store/
    persistence.ts  localStorage 整体落盘/读取/重置
  components/       页面交互：批次列表、处置队列、监测录入、时间线、履历留档
  App.tsx           组装：所有操作经引擎计算后 setState，useEffect 统一持久化
```

列表、时间线、履历均从同一份状态派生，状态变化整体落盘，刷新后三者一致。
